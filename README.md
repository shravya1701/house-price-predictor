# House Price Predictor

End-to-end regression project for predicting house prices using three machine-learning models.

## Requirements Covered

- Housing dataset
- EDA and data cleaning
- `train_test_split`
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- 5-fold cross-validation
- RMSE model comparison
- Winning-model feature importance
- Residuals plot
- Explanation of why the winning model performed best
- GitHub-ready README

## Dataset

Use the Kaggle House Prices `train.csv` and place it at:

```text
data/train.csv
```

The notebook also attempts to download a public mirror automatically if that file is missing.

## How to Run

```bash
pip install -r requirements.txt
```

Then open `house_price_predictor.ipynb` in Jupyter, Google Colab, or VS Code and **Run All**.

The notebook creates the `outputs/` files automatically.

## Why the Winning Model Won

The winner is selected objectively using the lowest mean 5-fold cross-validation RMSE. RMSE penalizes larger errors, so a lower value indicates better predictive performance on unseen folds. Tree-based models can capture nonlinear relationships and interactions between housing features that a basic Linear Regression model cannot.

## Short Reflection

This project demonstrates an end-to-end machine-learning workflow rather than only fitting a model. Preprocessing is kept inside a scikit-learn pipeline to reduce leakage risk, and cross-validation makes the comparison more reliable. The residual and feature-importance plots add interpretability beyond a single score.
